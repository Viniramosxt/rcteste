# rcteste

A test repository with Jest testing configuration.

## Installation

```bash
npm install
```

## Running Tests

Run all tests:
```bash
npm test
```

Run tests in watch mode:
```bash
npm run test:watch
```

Run tests with coverage:
```bash
npm run test:coverage
```

## Project Structure

- `src/` - Source files
- `__tests__/` - Test files
- `jest.config.js` - Jest configuration
- `package.json` - Project dependencies and scripts

## Testing Framework

This project uses [Jest](https://jestjs.io/) for testing with the following features:
- Automated test discovery
- Code coverage reporting
- Watch mode for development
